### What's New page
When you ship a noteworthy user-facing change, add an entry to the What's New data file (`src/data/updates.json`) as part of the same task. Noteworthy means: a new feature or tool, a new calculator, diet, supplement, or peptide page (bundle multiple pages from one session into one entry), a meaningful improvement to an existing feature, or a fix to a bug users would have noticed. Skip refactors, SEO-only changes, styling tweaks, and internal tooling. Use today's date, plain language, short sentences, no em dashes, and mention the entry in your summary so I can review it.
